الملف الجاهز:
  bootanimation.zip   (~46 MB)

المواصفات:
  الدقة     : 720 × 1600
  الإطارات  : 40 (PNG)
  السرعة    : 5 fps
  الضغط     : Store (بدون ضغط) — متوافق مع أندرويد


======== طريقة التثبيت (Root) ========

1) انسخ الملف إلى الهاتف
2) باستخدام Root Explorer / MiXplorer / Terminal:

   نسخ احتياطي أولاً:
     cp /system/media/bootanimation.zip /sdcard/bootanimation_backup.zip

   ثم استبدل:
     adb root
     adb remount
     adb push bootanimation.zip /system/media/bootanimation.zip
     adb shell chmod 644 /system/media/bootanimation.zip
     adb reboot

   أو يدوياً:
     /system/media/bootanimation.zip
     أو /system/product/media/bootanimation.zip
     أو /oem/media/bootanimation.zip
     (حسب جهاز HONOR / Huawei)

3) صلاحيات الملف: 644 (rw-r--r--)
4) أعد تشغيل الهاتف


======== بدون روت (تطبيقات) ========

- Themes / Magisk module (إن وُجد)
- بعض أجهزة HONOR تدعم الثيمات الرسمية
